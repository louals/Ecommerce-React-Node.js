## Overview

Full-stack e-commerce platform with a React frontend and a Node.js backend.

## Tech Stack

React, Node.js

## Features

- React storefront
- Node.js REST API

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/Ecommerce-React-Node.js.git
cd Ecommerce-React-Node.js

# Backend
cd backend && npm install && npm start

# Frontend (in a second terminal)
cd frontend && npm install && npm run dev
```
> Adjust folder names to match the repository layout.
